**Senest lavet (18. november 2026): Lysuret uddybet (jeres valg 17. november 2026, prompten [prompt-tid-lysur.md](../arkiv/prompt-tid-lysur.md)).**
- **Jordens ur ved siden af:** Begge billeder i scene 2 er set fra Jorden ("Begge ure set fra Jorden", "Jordens ur · står stille" og "Skibets ur · farer forbi →"), tællerne hedder det samme, og en mærkat ved glimtet viser lysets fart. "Om bord ser det helt normalt ud" står i underteksten. Rejsen i tids lysur var allerede fjernet (14. november), så kun scene 2 er ændret.
- **"Uden og med Einstein"** (kontakterne i Indstillinger i scene 2): Uden Einstein får lyset skibets fart lagt oven i, og urene går ens. Lyset farer 1,32 gange lysets fart ved 87 % (ikke 2), og trekanten har siderne 1, 0,87 og 1,32. Forsøget fra 1964 med lys fra pioner står i "Ærligt talt" (faktatjekket i `docs/fakta-tid/hvorfor-langsommere.md`, CERN skrives ikke, fordi ingen læst kilde nævner det).
- **I turen, trin 4** (valgt af orkestratoren 2026-11-18, kan ændres af jer): Efter målebåndet spørger linjen "Hvad, hvis lyset kunne skynde sig som bolden?", og knapperne "Uden Einstein" og "Med Einstein" kommer frem. Så kommer efter 1,5 s med "Uden Einstein": "Dobbelt så lang. Lyset kan ikke skynde sig som bolden, så hvert tik tager dobbelt så lang tid set fra dig." "Næste ›" uden at prøve viser begge dele. Trin 3 siger "se skibets ur" i stedet for "se det nederste billede".
- **Tests:** `tidhvorfor` (fire nye tjek) og `tid-forloeb2` (tre nye tjek, og "af 13 set" efter Kosmos' forside).
