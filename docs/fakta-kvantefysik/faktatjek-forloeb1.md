# Faktatjek: turen "Prikker bliver til striber" (Kvantefysik, forløb 1, PR 2)

*20. november 2026. Teksterne står i `js/data/forloeb/kvante.js` og slutteksten i `js/kvante.js` (`DEL.slutTekst`). Kilderne er [fakta-kvantefysik.md](../fakta-kvantefysik.md) (afsnit 1, 7 og 8, læst 13. november 2026) og fælderne i [fakta-faelder.md](../erfaringer/fakta-faelder.md). Ingen nye kilder var nødvendige: Alle påstande står i faktagrundlaget. E7-rettelserne (afsnit 3, punkt 1 og 7) er fulgt.*

| Påstand | Vurdering | Kilde |
|---|---|---|
| Kugler gennem to sprækker giver to striber, én bag hver sprække, og resten stopper i væggen | OK | Klassisk mekanik (Feynman Lectures III, kap. 1, i faktagrundlaget afsnit 1) |
| Vandets bølger giver mange striber: Hvor en bølgetop møder en bølgedal, bliver vandet stille. Det hedder interferens | OK | Faktagrundlaget afsnit 1 (Young, bølger) |
| Elektroner sendt én ad gangen lander hver som én prik, men mange prikker danner striberne | OK | Merli, Missiroli og Pozzi 1974, Tonomura m.fl. 1989 (afsnit 1, S/RS) |
| Lukkes én sprække, lander der flere elektroner ved et mørkt sted | OK | Faktagrundlaget afsnit 1 (med én sprække er der ikke noget mørkt sted inden for den brede bunke). Spillets model: ca. 9 før og ca. 85 efter ved 1.000 elektroner, tallene er spillets egne ("Ærligt talt" siger det) |
| "Bølgen går gennem begge, og de to dele slukker hinanden her" | OK | Fælden "to steder på én gang" er undgået: Det er bølgen, ikke partiklen, der går gennem begge |
| Måleren finder altid en hel elektron ved én sprække, og de mørke striber er væk | OK | Afsnit 1 og E7 punkt 1: ÉN bred bunke (ikke "som kuglerne") |
| Kernesætningen ("… forsvinder striberne") | OK | Jeres go på drejebogens kernesætning. Med måler er der kun én bred bunke uden striber |
| "I 1989 så forskere hos Hitachi de samme striber komme frem af rigtige elektroner, én ad gangen. Det tog ca. 20 minutter." | OK | hitachi.com (afsnit 1, S). Fælderne: "én ad gangen" og "ca. 20 minutter", ikke "10 i sekundet". Teksten siger ikke "to sprækker" (det var et elektron-biprisme) |

**Resultat:** Ingen rettelser. Ingen nye fagord (interferens stod i Ordbogen fra PR 1). Ingen nye fælder.
